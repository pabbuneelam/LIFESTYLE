APPLE HEALTH

Step sync

Not synced

Bring today's step count in from Apple Health with a one-time iPhone Shortcut. Step goals like "Hit 10,000 steps" tick themselves when you reach them.

Type it exactly as it appears on the shortcut's tile in the Shortcuts app, capitals and spaces included.

Set up the Shortcut (one time, about 2 minutes)
  1. Open the Shortcuts app, tap ＋, and name the new shortcut LIFESTYLE Steps. If you name it something else, type that name in the box above. To rename it later, open the shortcut and tap its name at the top.
  2. Add Find Health Samples. Set the type to Steps, add the filter Start Date is Today, and set Group By to Day.
  3. Add Calculate Statistics and choose Sum.
  4. Add Round Number (Ones Place).
  5. Add Copy to Clipboard. It should read Copy Rounded Number to clipboard; if not, tap the blue field and pick Rounded Number.
  6. Run it once and tap Allow when it asks for Health access. If it copies 0 or nothing, turn on Steps in Settings → Health → Data Access & Devices → Shortcuts.

Daily use: tap Sync steps, let the shortcut run, come back here and tap Import steps. Your iPhone will ask to allow pasting.

Keep it updated automatically: in Shortcuts, open Automation → ＋ → Time of Day. Pick a time, set it to Daily and Run Immediately, then choose your step shortcut. Add a few (for example 9 AM, 12 PM, 3 PM, 6 PM and 9 PM). Whenever you open LIFESTYLE and your steps are over 30 minutes old, it offers Update steps, one tap and done. Automations can't read Health while your iPhone is locked, so a run that fires while it's locked may skip.

Using LIFESTYLE in a browser instead of the home screen? Replace the last step with Open URLs pointing to Rounded Number and the steps arrive automatically.
